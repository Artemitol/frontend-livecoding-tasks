Потренируйтесь рассуждать о порядке и актуальности асинхронных действий. Первая задача разбирает очереди event loop, вторая — гонку ответов поиска.

После задачи нажмите «Назад», чтобы вернуться к этому списку.

1. [Порядок синхронного кода, microtask и timer callback](../../../tasks/browser-event-loop-order/README.md) — Определите порядок обычного кода, Promise и setTimeout в браузере. Примерно 12 минут.
2. [Актуальный результат поиска при гонке ответов](../../../tasks/stale-search-response/README.md) — Исправьте поиск так, чтобы поздний устаревший ответ не заменял новый. Примерно 25 минут.
