# Массивы и объекты

Потренируйтесь преобразовывать коллекции без неожиданных мутаций. Задачи идут от прямой агрегации к сортировке по нескольким правилам.

После задачи нажмите «Назад», чтобы вернуться к этому списку.

1. [Итоги по категориям без мутаций](../../../tasks/immutable-category-totals/README.md) — Научитесь проверять данные и собирать суммы по категориям, не меняя исходный массив. Примерно 15 минут.
2. [Стабильная сортировка товаров по двум ключам](../../../tasks/stable-product-sort/README.md) — Исправьте сортировку по наличию и цене, сохранив порядок равных элементов. Примерно 20 минут.
