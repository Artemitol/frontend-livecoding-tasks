# Сужение и проверка данных

Научитесь безопасно переходить от широкого типа к проверенному значению. Задачи идут от готового union к полной runtime-проверке unknown.

После задачи нажмите «Назад», чтобы вернуться к этому списку.

1. [Безопасная обработка результата запроса](../../../tasks/response-union-narrowing/README.md) — Исправьте сужение успешного и ошибочного результата запроса. Примерно 20 минут.
2. [Проверка JSON-профиля без assertion](../../../tasks/validate-unknown-profile/README.md) — Проверьте unknown JSON и получите типизированный результат без assertion. Примерно 30 минут.
