# TypeScript: практика к собеседованию

Задачи на типобезопасные функции, вывод типов и ограничения ключей TypeScript.

1. [Типизированный выбор полей объекта](../../../tasks/task-0038/README.md) — Верните выбранные поля объекта с сохранением типов значений. — 25 минут
2. [Типизированная интеграция браузерного скрипта](../../../tasks/task-0057/README.md) — Исправьте типы, загрузчик, options, навигацию и запуск браузерного renderer. — 30 минут
3. [Собственная реализация Partial](../../../tasks/task-0101/README.md) — Сделайте все поля объекта необязательными, сохранив типы значений. — 20 минут
4. [Объединение ключей объекта](../../../tasks/task-0102/README.md) — Получите допустимые строковые ключи из объявленного объекта. — 15 минут
5. [Собственная реализация Pick](../../../tasks/task-0103/README.md) — Оставьте только выбранные ключи объекта с исходными типами. — 20 минут
6. [Пути к строковым листьям](../../../tasks/task-0104/README.md) — Рекурсивно сформируйте точечные пути только к строковым листьям. — 30 минут
7. [Ключи по разрешаемому типу](../../../tasks/task-0105/README.md) — Отберите ключи по прямому, Promise или возвращаемому функцией значению. — 30 минут
8. [Типизированное чтение свойства](../../../tasks/task-0106/README.md) — Свяжите допустимый ключ и тип возвращаемого значения с объектом. — 20 минут
