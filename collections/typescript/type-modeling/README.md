# Моделирование типов

Потренируйтесь выражать связи между состояниями, ключами и значениями в типах. Сначала смоделируйте состояния, затем сохраните точный тип свойства.

После задачи нажмите «Назад», чтобы вернуться к этому списку.

1. [Взаимоисключающие состояния загрузки](../../../tasks/discriminated-load-state/README.md) — Опишите допустимые состояния через discriminated union и исчерпывающий switch. Примерно 20 минут.
2. [Точный тип значения по ключу настройки](../../../tasks/typed-object-property/README.md) — Свяжите generic-ключ объекта с точным типом возвращаемого значения. Примерно 20 минут.
