# React: эффекты и жизненный цикл

Разберитесь, как React синхронизируется с внешними ресурсами. Задачи покрывают зависимости effect, cleanup и проверочный цикл StrictMode.

После задачи нажмите «Назад», чтобы вернуться к этому списку.

1. [Подписка, которая следует за выбранным каналом](../../../tasks/react-effect-subscription/README.md) — Синхронизируйте подписку с выбранным каналом и снимайте старый ресурс. 25 минут.
2. [Идемпотентный cleanup в корневом StrictMode](../../../tasks/react-strictmode-cleanup/README.md) — Сделайте cleanup одного ресурса повторно безопасным в корневом StrictMode. 30 минут.
3. [Список пользователей из API](../../../tasks/users-api-list/README.md) — Соберите список с пагинацией, отправляемым поиском и полными состояниями удалённого ресурса. 60 минут.
