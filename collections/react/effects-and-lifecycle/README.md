# React: эффекты и жизненный цикл

Разберитесь, как React синхронизируется с внешними ресурсами. Задачи покрывают зависимости effect, cleanup и проверочный цикл StrictMode.

После задачи нажмите «Назад», чтобы вернуться к этому списку.

1. [Подписка, которая следует за выбранным каналом](../../../tasks/react-effect-subscription/README.md) — Синхронизируйте подписку с выбранным каналом и снимайте старый ресурс. Примерно 25 минут.
2. [Идемпотентный cleanup в корневом StrictMode](../../../tasks/react-strictmode-cleanup/README.md) — Объясните дополнительный цикл StrictMode и сделайте cleanup повторно безопасным. Примерно 30 минут.
