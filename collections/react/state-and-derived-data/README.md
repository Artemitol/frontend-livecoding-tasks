# React: состояние и производные данные

Потренируйтесь отличать состояние от данных, которые можно вычислить. Затем исправьте обновления, зависящие от предыдущего state.

После задачи нажмите «Назад», чтобы вернуться к этому списку.

1. [Производный список без копии состояния](../../../tasks/react-derived-list/README.md) — Вычисляйте отфильтрованный список из props и state без дублирования данных. Примерно 20 минут.
2. [Три обновления счётчика в одном событии](../../../tasks/react-batched-counter/README.md) — Исправьте три batched-обновления через функциональную форму setState. Примерно 15 минут.
