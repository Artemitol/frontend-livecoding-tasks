# Вёрстка

Потренируйтесь исправлять раскладку без JavaScript. Сначала разберите flex-переполнение, затем постройте сетку от ширины контейнера.

После задачи нажмите «Назад», чтобы вернуться к этому списку.

1. [Длинное слово во flex-строке](../../../tasks/flex-long-text-overflow/README.md) — Разрешите flex-элементу сжиматься и переносить длинное слово без обрезки. Примерно 20 минут.
2. [Сетка карточек от ширины контейнера](../../../tasks/container-responsive-grid/README.md) — Соберите grid, который меняет число колонок по ширине контейнера. Примерно 30 минут.
