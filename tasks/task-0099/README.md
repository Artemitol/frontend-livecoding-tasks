<details>
<summary>Подсказка 1 — куда смотреть</summary>

Найдите первую букву слова, не считая дефис началом нового слова.

</details>

<details>
<summary>Подсказка 2 — с чего начать</summary>

Регулярное выражение может выделить слово целиком, включая внутренние дефисы.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

Используйте `/[A-Za-zА-Яа-яЁё]+(?:-[A-Za-zА-Яа-яЁё]+)*/g` и для каждого найденного слова меняйте только `word[0]`.

</details>

<details>
<summary>Решение</summary>

```javascript
function capitalize(input) {
  return input.replace(/[A-Za-zА-Яа-яЁё]+(?:-[A-Za-zА-Яа-яЁё]+)*/g, (word) => (
    word[0].toUpperCase() + word.slice(1)
  ));
}
```

Замена применяется к слову целиком, поэтому первая буква после дефиса не меняется.

Ожидаемый результат: `'А Роза Упала На Лапу Азора'`, `'Что-то И Кто-либо'`.

Ручная проверка: передайте `'hello, мир!'`; результат должен быть `'Hello, Мир!'`.

</details>
