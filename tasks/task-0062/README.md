# Сумма с цепочкой каррированных вызовов

Песочница для выполнения — [Programiz](https://www.programiz.com/javascript/online-compiler/).

## Условие
```javascript
// Реализуйте sum(first): каждый следующий вызов с числом добавляет его к сумме и возвращает ту же цепочку, а пустой вызов завершает вычисление.
// Длина цепочки заранее неизвестна; ноль и отрицательные числа считаются обычными слагаемыми.
// Проверки ниже должны вывести 1, 6 и 3; используйте консольный JavaScript без ESM и browser API.

function sum(first) {
  // Напишите решение.
}

console.log(sum(1)());
console.log(sum(1)(2)(3)());
console.log(sum(0)(-2)(5)());
```

<details>
<summary>Подсказка 1 — куда смотреть</summary>

Нужно вернуть функцию, которая замыкает накопленную сумму и при необходимости возвращает саму себя.

</details>

<details>
<summary>Подсказка 2 — с чего начать</summary>

Сохраните `first` в переменной `total`, затем объявите внутреннюю обычную функцию `collect(next)`.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

Внутри `collect` проверяйте `arguments.length`: пустой вызов возвращает `total`, а вызов с аргументом увеличивает сумму и возвращает `collect`.

</details>

<details>
<summary>Решение</summary>

```javascript
function sum(first) {
  let total = first;

  function collect(next) {
    if (arguments.length === 0) {
      return total;
    }

    total += next;
    return collect;
  }

  return collect;
}
```

Каждая цепочка получает собственный `total`. Проверка наличия аргумента, а не его истинности, позволяет добавлять ноль и завершать вычисление только пустыми скобками.

Ожидаемый результат: строки `1`, `6`, `3`.

Ручная проверка: вставьте решение и сравните три строки; затем создайте две цепочки из разных вызовов `sum` и убедитесь, что их накопленные суммы не влияют друг на друга.

</details>
