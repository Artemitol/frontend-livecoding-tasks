# task-0109 — Сравнение десятичных дробей

Песочница для выполнения — [Programiz](https://www.programiz.com/javascript/online-compiler/).

## Условие
```javascript
// Предскажите значение expression и объясните его через двоичное представление дробей IEEE 754.
// Не изменяйте выражение; сравнение должно остаться строгим.

const expression = 0.1 + 0.2 === 0.3;

console.log(expression);
console.log(0.1 + 0.2);
```

<details>
<summary>Подсказка 1 — куда смотреть</summary>

Не все десятичные дроби имеют конечное двоичное представление.

</details>

<details>
<summary>Подсказка 2 — с чего начать</summary>

Сначала запустите оба `console.log` и сравните сумму с литералом `0.3`.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

Сумма представляется как число, близкое к `0.3`, но не равное ему точно.

</details>

<details>
<summary>Решение</summary>

```javascript
const expression = 0.1 + 0.2 === 0.3;

console.log(expression);
console.log(0.1 + 0.2);
```

Дроби `0.1` и `0.2` округляются в двоичном формате, поэтому их сумма не является точным `0.3`.

Ожидаемый результат: `false`, затем `0.30000000000000004`.

Ручная проверка: выведите `(0.1 + 0.2).toFixed(20)` и сравните с `0.3.toFixed(20)`.

</details>
