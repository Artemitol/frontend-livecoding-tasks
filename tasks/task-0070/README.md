# task-0070 — Переприсваивание const внутри IIFE

Песочница для выполнения — [Programiz](https://www.programiz.com/javascript/online-compiler/).

## Условие
```javascript
// Не изменяя код, предскажите результат: укажите точный тип ошибки и выполнится ли console.log.
// Объясните разницу между изменением свойства объекта и переприсваиванием переменной, объявленной через const.

const person = {
  name: 'Vasya',
};

(function replacePerson() {
  person = {
    name: 'Petya',
  };
})(person);

console.log(person.name);
```

<details>
<summary>Подсказка 1 — куда смотреть</summary>

`const` запрещает присвоить переменной новую ссылку, хотя свойства исходного объекта можно было бы изменить.

</details>

<details>
<summary>Подсказка 2 — с чего начать</summary>

IIFE выполняется синхронно до `console.log`, а переданный аргумент не создаёт параметр: функция обращается к внешней переменной `person`.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

Строка `person = { ... }` пытается переприсвоить `const` и немедленно бросает `TypeError`, поэтому выполнение до следующей строки не доходит.

</details>

<details>
<summary>Решение</summary>

```text
TypeError при попытке выполнить person = { name: 'Petya' }
console.log не выполняется
```

Константа хранит ссылку на исходный объект и не может получить новую ссылку. Ошибка возникает внутри синхронного IIFE и останавливает скрипт до чтения `person.name`.

Ожидаемый результат: `TypeError` при переприсваивании `person`; строки с именем в консоли нет.

Ручная проверка: сначала запишите прогноз, затем запустите блок; после этого отдельно замените присваивание на `person.name = 'Petya'` и убедитесь, что изменение свойства допустимо и лог выводит `Petya`.

</details>
