## Условие

```js
// Учебная цель: объяснять значения, захваченные замыканиями
// при создании функций внутри цикла.
//
// До запуска предскажите одну точную строку консоли.
// Затем составьте trace трёх итераций:
// index при создании, snapshot и результат callback.
// Код не изменяйте и не заменяйте let на var.

const callbacks = [];

for (let index = 0; index < 3; index += 1) {
  const snapshot = index * 10;
  callbacks.push(() => `${index}:${snapshot}`);
}

console.log(callbacks.map((callback) => callback()).join(', '));
```

## Готово, когда

- До запуска записана точная строка `0:0, 1:10, 2:20`.
- Trace содержит три отдельные итерации со значениями `0/0`, `1/10` и `2/20`.
- Объяснение связывает результат с отдельной привязкой `let` для каждой итерации, а не с поздним чтением одной общей переменной.

<details>
<summary>Решение</summary>

```js
const callbacks = [];

for (let index = 0; index < 3; index += 1) {
  const snapshot = index * 10;
  callbacks.push(() => `${index}:${snapshot}`);
}

console.log(callbacks.map((callback) => callback()).join(', '));
```

Точный вывод:

```text
0:0, 1:10, 2:20
```

| Итерация | `index` при создании | `snapshot` | Результат callback |
| --- | --- | --- | --- |
| 1 | 0 | 0 | `0:0` |
| 2 | 1 | 10 | `1:10` |
| 3 | 2 | 20 | `2:20` |

### Почему это работает

Цикл с `let` создаёт отдельную привязку `index` для каждой итерации. Каждая стрелка замыкается на свою привязку и на объявленный рядом `snapshot`, поэтому после завершения цикла callback-функции не читают общее значение `3`.

</details>
