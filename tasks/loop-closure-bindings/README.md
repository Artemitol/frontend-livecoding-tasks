# Замыкания, созданные внутри цикла

**Учебная цель:** Объяснять значения, захваченные замыканиями при создании функций внутри цикла.

| Метаданные | Значение |
| --- | --- |
| Технологии | JavaScript |
| Тема | Модель выполнения JavaScript |
| Формат | Прогноз вывода |
| Уровень | Базовый |
| Время | 10 минут |
| Навыки | область видимости `let`, замыкания, пошаговый trace |
| Предварительные знания | Нет |
| Среда выполнения | Node.js 26.4.0, ECMAScript modules |

<details>
<summary>Теория</summary>

Замыкание хранит доступ к лексическим привязкам, а не текстовую копию выражения. В цикле с `let` для каждой итерации создаётся отдельная привязка переменной цикла. Поэтому функции, созданные на разных итерациях, обращаются к разным значениям `index`.

</details>

## Условие

Не запуская код сначала, предскажите точный вывод и объясните, какие значения захватывает каждая функция из `callbacks`.

### Входы

Дана фиксированная программа. В письменном ответе укажите:

1. одну точную строку stdout;
2. trace из трёх итераций с `index`, `snapshot` и значением, которое вернёт созданная функция.

### Выходы

Одна строка stdout и причинное объяснение привязок замыкания.

### Ограничения и побочные эффекты

- Не изменяйте код и не заменяйте `let` на `var`.
- В этой задаче нет пользовательского входа, ошибок валидации или отдельного пустого результата.
- Единственный побочный эффект программы — вывод одной строки в stdout.

### Фикстуры

Фикстура — приведённая ниже неизменяемая программа.

### Стартовый код

```js
const callbacks = [];

for (let index = 0; index < 3; index += 1) {
  const snapshot = index * 10;
  callbacks.push(() => `${index}:${snapshot}`);
}

console.log(callbacks.map((callback) => callback()).join(', '));
```

### Примеры

#### Обычный сценарий

Для первой итерации создаётся функция с `index === 0` и `snapshot === 0`, поэтому первый фрагмент вывода — `0:0`.

#### Граничный сценарий

Третья и последняя итерация создаёт функцию с `index === 2` и `snapshot === 20`; её результат — `2:20`.

#### Ошибка или пустой результат

Не применяется: программа не принимает вход и не имеет ветки ошибки или пустого результата.

## Критерии готовности

- Указана точная строка `0:0, 1:10, 2:20`.
- Trace содержит три отдельные итерации со значениями `0/0`, `1/10` и `2/20`.
- Объяснение связывает результат с отдельными привязками `let`, а не с поздним чтением одной общей переменной.

<details>
<summary>Подсказка 1</summary>

Рассматривайте каждую итерацию отдельно: функция создаётся до перехода к следующему значению `index`.

</details>

<details>
<summary>Решение</summary>

### Подход

Тело цикла выполняется для `index` 0, 1 и 2. На каждой итерации `snapshot` вычисляется один раз, а замыкание получает доступ к собственной итерационной привязке `index` и к соответствующему `snapshot`.

| Итерация | `index` при создании | `snapshot` | Результат callback |
| --- | --- | --- | --- |
| 1 | 0 | 0 | `0:0` |
| 2 | 1 | 10 | `1:10` |
| 3 | 2 | 20 | `2:20` |

Поэтому stdout:

```text
0:0, 1:10, 2:20
```

Полный код не требует исправлений:

```js
const callbacks = [];

for (let index = 0; index < 3; index += 1) {
  const snapshot = index * 10;
  callbacks.push(() => `${index}:${snapshot}`);
}

console.log(callbacks.map((callback) => callback()).join(', '));
```

### Сложность

- Время: `O(n)` для создания и вызова `n` callback-функций.
- Память: `O(n)` для массива callback-функций и их замыканий.

### Компромиссы и альтернативы

`let` выражает нужную область видимости напрямую. При `var` все callback-функции читали бы одну общую переменную цикла после его завершения; это можно компенсировать фабрикой функции или IIFE, но такой код сложнее и хуже передаёт намерение.

</details>
