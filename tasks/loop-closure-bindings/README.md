# Замыкания, созданные внутри цикла

Сначала запишите свой прогноз. Затем откройте [Programiz JavaScript Online Compiler](https://www.programiz.com/javascript/online-compiler/), полностью замените код блоком ниже и нажмите **Run**. Используйте консольный JavaScript; режим ESM не меняет здесь семантику `let` и замыканий.

## Условие

Не изменяя код, предскажите единственную строку консоли. Затем объясните для каждой итерации значение `index` при создании функции, значение `snapshot` и результат вызова callback после завершения цикла.

```javascript
const callbacks = [];

for (let index = 0; index < 3; index += 1) {
  const snapshot = index * 10;
  callbacks.push(() => `${index}:${snapshot}`);
}

console.log(callbacks.map((callback) => callback()).join(', '));
```

<details>
<summary>Подсказка 1 — куда смотреть</summary>

Обратите внимание на `let index` в заголовке цикла и `const snapshot` внутри его тела.

</details>

<details>
<summary>Подсказка 2 — с чего начать</summary>

Разберите первую итерацию отдельно: зафиксируйте `index`, вычислите `snapshot`, а затем рассмотрите созданную стрелочную функцию.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

Повторите trace для `index` от `0` до `2`: каждая функция получает привязку своей итерации, после чего три результата соединяются через `, `.

</details>

<details>
<summary>Решение</summary>

Ожидаемый вывод:

```text
0:0, 1:10, 2:20
```

| Итерация | `index` при создании | `snapshot` | Результат callback |
| --- | --- | --- | --- |
| 1 | 0 | 0 | `0:0` |
| 2 | 1 | 10 | `1:10` |
| 3 | 2 | 20 | `2:20` |

Цикл с `let` создаёт отдельную привязку `index` для каждой итерации. Каждая функция замыкается на свою привязку и соответствующий `snapshot`, поэтому после цикла callbacks не читают одно общее значение `3`. Для ручной проверки сравните прогноз с единственной строкой после **Run**.

</details>
