# Приоритет && и || с коротким замыканием

Песочница для выполнения — [Programiz](https://www.programiz.com/javascript/online-compiler/).

## Условие
```javascript
// Не изменяя код, предскажите порядок всех вызовов и последнюю строку console.log.
// Объясните ответ через приоритет && над || и короткое замыкание после первого truthy-результата.
// Используйте консольный JavaScript без ESM и browser API.

function f0() {
  console.log('f0');
  return 0;
}

function f1() {
  console.log('f1');
  return 1;
}

function f2() {
  console.log('f2');
  return 2;
}

function f3() {
  console.log('f3');
  return 3;
}

function f4() {
  console.log('f4');
  return 4;
}

console.log(f0() || f1() && f2() || f3() && f4());
```

<details>
<summary>Подсказка 1 — куда смотреть</summary>

Сначала сгруппируйте пары с `&&`: этот оператор имеет более высокий приоритет, чем `||`.

</details>

<details>
<summary>Подсказка 2 — с чего начать</summary>

`f0` возвращает falsy `0`, поэтому вычисление продолжится к следующей части выражения.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

`f1() && f2()` возвращает `2`; это truthy-значение останавливает внешнее `||`, поэтому `f3` и `f4` не вызываются.

</details>

<details>
<summary>Решение</summary>

```text
f0
f1
f2
2
```

Сначала вызывается `f0`. Затем из-за приоритета `&&` выполняется связка `f1() && f2()`, которая возвращает последнее truthy-значение `2`. Оно прекращает дальнейшее вычисление `||`.

Ожидаемый результат: вызовы `f0`, `f1`, `f2`, затем внешний `console.log` выводит `2`.

Ручная проверка: запустите блок и убедитесь, что строк `f3` и `f4` в консоли нет.

</details>
