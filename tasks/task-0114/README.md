# Сложение пустых массива и объекта

Песочница для выполнения — [Programiz](https://www.programiz.com/javascript/online-compiler/).

## Условие
```javascript
// Не изменяя код, предскажите две строки вывода для сложения пустых массива и объекта в разном порядке.
// Объясните результат через приведение операндов к примитивам; круглые скобки фиксируют оба выражения как выражения JavaScript.
// Используйте консольный JavaScript без ESM и browser API.

const arrayFirst = ([] + {});
const objectFirst = ({} + []);

console.log(arrayFirst);
console.log(objectFirst);
```

<details>
<summary>Подсказка 1 — куда смотреть</summary>

Оператор `+` сначала приводит объекты к примитивным значениям.

</details>

<details>
<summary>Подсказка 2 — с чего начать</summary>

Пустой массив превращается в пустую строку, а обычный пустой объект — в строку `"[object Object]"`.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

После строкового приведения порядок уже не меняет текст: в обоих случаях получается `"[object Object]"`.

</details>

<details>
<summary>Решение</summary>

```text
[object Object]
[object Object]
```

Скобки устраняют неоднозначность синтаксической позиции `{}`. В обоих выражениях один операнд становится пустой строкой, а другой — строковым представлением объекта, поэтому `+` выполняет конкатенацию.

Ожидаемый результат: две одинаковые строки `[object Object]`.

Ручная проверка: запустите блок, затем выведите отдельно `String([])` и `String({})`.

</details>
