# Длинное слово во flex-строке

**Учебная цель:** Исправлять переполнение flex-элемента длинным текстом без обрезки содержимого.

| Метаданные | Значение |
| --- | --- |
| Технологии | HTML, CSS |
| Тема | CSS-раскладка |
| Формат | Отладка |
| Уровень | Средний |
| Время | 20 минут |
| Навыки | Flexbox, min-width, overflow-wrap, ручная проверка раскладки |
| Предварительные знания | Базовая flex-раскладка |
| Среда выполнения | Google Chrome 150.0.7871.101, viewport 640 CSS px, manual visual scenario |

<details>
<summary>Теория</summary>

Flex item по умолчанию не всегда готов сжиматься меньше минимального размера содержимого. Для длинного неразрывного слова это может расширить всю страницу. Разрешите текстовому item сжиматься через `min-width: 0` и разрешите перенос внутри слова через `overflow-wrap: anywhere`.

</details>

## Условие

Исправьте CSS flex-строки на viewport 640 CSS px. Всё длинное слово должно быть видно, а document body не должен получать горизонтальную прокрутку.

### Входы

- Фиксированный label, кнопка и длинная строка без пробелов.
- Viewport ровно 640 CSS px.

### Выходы

- Длинное слово занимает несколько визуальных строк, не исчезая и не обрезаясь.
- `document.documentElement.scrollWidth === document.documentElement.clientWidth`.

### Ограничения и побочные эффекты

- Не удаляйте текст и не применяйте ellipsis, `clip` или `hidden` для сокрытия содержимого.
- Не используйте JavaScript-измерение как способ раскладки.
- Проверка — ручная в браузере, не CSS unit test.

### Локальный fixture

```html
<div class="flex-row">
  <strong>Статус</strong>
  <p>Оченьдлинноесловобезпробеловкотороедолжнопереноситьсяивсецеликомоставатьсявидимымвнутриflexэлемента</p>
  <button>Открыть</button>
</div>
```

### Стартовый код

```css
.flex-row { display: flex; align-items: flex-start; gap: 12px; }
.flex-row p { margin: 0; flex: 1 1 auto; }
.flex-row button { flex: 0 0 auto; }
```

### Примеры

#### Обычный сценарий

На ширине 640 CSS px label, весь текст и кнопка остаются видимыми.

#### Граничный сценарий

Неразрывная строка переносится внутри слова, а не расширяет document body.

#### Ошибка или пустой результат

Горизонтальная прокрутка страницы или скрытая часть слова означают непрохождение.

## Критерии готовности

- Текстовый flex item может сжиматься.
- Длинная строка переносится внутри слова.
- На 640 CSS px нет body overflow.
- Ручная проверка подтверждает видимость всех символов.

<details>
<summary>Подсказка 1</summary>

Проверьте не только `flex-grow`, но и минимальную ширину текстового flex item.

</details>

<details>
<summary>Решение</summary>

### Подход

`min-width: 0` снимает автоматический минимум flex item, а `overflow-wrap: anywhere` даёт браузеру легальное место переноса в длинном слове.

```css
.flex-row { display: flex; align-items: flex-start; gap: 12px; }
.flex-row p {
  min-width: 0;
  overflow-wrap: anywhere;
  margin: 0;
  flex: 1 1 auto;
}
.flex-row button { flex: 0 0 auto; }
```

### Сложность

- Время: браузерная раскладка; отдельного алгоритма JavaScript нет.
- Память: дополнительная прикладная память не требуется.

### Компромиссы и альтернативы

`word-break: break-all` переносит агрессивнее и хуже читается для обычного текста. `overflow-wrap: anywhere` сохраняет нормальные переносы, пока они возможны. Ellipsis подходит только когда контракт прямо разрешает потерю видимой части текста.

</details>
