# Длинное слово во flex-строке

[← Все подборки](../../README.md)

## Условие

Исправьте переполнение текстового flex-элемента: длинное слово должно переноситься целиком, а страница — оставаться без горизонтальной прокрутки. Учебная цель — управлять минимальной шириной flex item и переносом неразрывного текста без обрезки содержимого. Перед началом нужна базовая flex-раскладка.

Откройте [CodePen](https://pen.new), очистите панели HTML, CSS и JS, вставьте весь блок ниже в панель **HTML** и нажмите **Run**. Код не обращается к сети. Исходный ручной сценарий рассчитан на Google Chrome 150.0.7871.101: перед проверкой выставьте viewport результата ровно `640 CSS px` и не подменяйте визуальную проверку CSS unit test.

## Код — вставьте его в редактор

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="utf-8">
    <title>Длинное слово во flex-строке</title>
    <style>
      * {
        box-sizing: border-box;
      }

      body {
        margin: 2rem;
        font: 16px/1.5 system-ui;
      }

      /*
       * Учебная цель: исправить переполнение flex-элемента длинным
       * текстом без обрезки содержимого.
       * Перед началом нужна базовая flex-раскладка.
       *
       * Исправьте только правила .flex-row p:
       * 1. разрешите текстовому flex item сжиматься;
       * 2. разрешите перенос внутри длинного слова.
       * Не скрывайте и не обрезайте текст, не добавляйте JavaScript.
       */
      .flex-row {
        display: flex;
        align-items: flex-start;
        gap: 12px;
        padding: 1rem;
        border: 1px solid #777;
      }

      .flex-row p {
        margin: 0;
        flex: 1 1 auto;
      }

      .flex-row button {
        flex: 0 0 auto;
      }
    </style>
  </head>
  <body>
    <main>
      <h1>Статус доставки</h1>
      <div class="flex-row">
        <strong>Статус</strong>
        <p>Оченьдлинноесловобезпробеловкотороедолжнопереноситьсяивсецеликомоставатьсявидимымвнутриflexэлемента</p>
        <button type="button">Открыть</button>
      </div>
    </main>
  </body>
</html>
```

## Готово, когда

- При viewport ровно `640 CSS px` видны label, кнопка и все символы длинного слова; слово занимает несколько визуальных строк без clipping, ellipsis или скрытия.
- В Console выражение `document.documentElement.scrollWidth === document.documentElement.clientWidth` возвращает `true`.
- Раскладка решена CSS-свойствами текстового flex item: JavaScript не измеряет и не изменяет её.

<details>
<summary>Подсказка 1 — куда смотреть</summary>

У flex item есть автоматическая минимальная ширина, которая может следовать минимальному размеру его содержимого. Одного `flex: 1` для длинного неразрывного слова недостаточно.

</details>

<details>
<summary>Подсказка 2 — с чего начать</summary>

Разрешите элементу с текстом стать уже его содержимого через свойство минимальной ширины. После этого отдельно решите, где браузер может перенести слово без пробелов.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

Для `.flex-row p` нужны два независимых правила: минимальная ширина `0` и перенос, который разрешает точку разрыва в любом месте слишком длинного слова.

</details>

<details>
<summary>Решение</summary>

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="utf-8">
    <title>Длинное слово во flex-строке</title>
    <style>
      * {
        box-sizing: border-box;
      }

      body {
        margin: 2rem;
        font: 16px/1.5 system-ui;
      }

      .flex-row {
        display: flex;
        align-items: flex-start;
        gap: 12px;
        padding: 1rem;
        border: 1px solid #777;
      }

      .flex-row p {
        min-width: 0;
        overflow-wrap: anywhere;
        margin: 0;
        flex: 1 1 auto;
      }

      .flex-row button {
        flex: 0 0 auto;
      }
    </style>
  </head>
  <body>
    <main>
      <h1>Статус доставки</h1>
      <div class="flex-row">
        <strong>Статус</strong>
        <p>Оченьдлинноесловобезпробеловкотороедолжнопереноситьсяивсецеликомоставатьсявидимымвнутриflexэлемента</p>
        <button type="button">Открыть</button>
      </div>
    </main>
  </body>
</html>
```

### Почему это работает

`min-width: 0` снимает автоматический минимум текстового flex item и разрешает ему занять доступную ширину между label и кнопкой. `overflow-wrap: anywhere` создаёт допустимые точки переноса внутри длинного слова, не удаляя символы. `word-break: break-all` был бы агрессивнее для обычного текста, а `overflow: hidden` и ellipsis нарушили бы условие видимости.
