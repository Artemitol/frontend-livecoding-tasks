# Длинное слово во flex-строке

Откройте [CodePen](https://pen.new), вставьте HTML и CSS в одноимённые панели. Код не использует JavaScript; проверка выполняется по описанному в карточке ручному сценарию.

## Условие

Исправьте только правило `.flex-row p`: текстовый flex item должен сжиматься, длинное слово — переноситься без обрезки, а строка — оставаться без горизонтального переполнения. Не используйте `overflow: hidden`, ellipsis или JavaScript.

```html
<div class="flex-row">
  <strong>Статус</strong>
  <p>Оченьдлинноесловобезпробеловкотороедолжнопереноситьсяивсецеликомоставатьсявидимымвнутриflexэлемента</p>
  <button type="button">Открыть</button>
</div>
```

```css
* {
  box-sizing: border-box;
}

.flex-row {
  display: flex;
  align-items: flex-start;
  gap: 12px;
  padding: 1rem;
  border: 1px solid #777;
}

.flex-row p {
  margin: 0;
  flex: 1 1 auto;
}

.flex-row button {
  flex: 0 0 auto;
}
```

<details>
<summary>Подсказка 1 — куда смотреть</summary>

Автоматическая минимальная ширина flex item может следовать минимальному размеру содержимого. Одного `flex: 1` для длинного слова недостаточно.

</details>

<details>
<summary>Подсказка 2 — с чего начать</summary>

Сначала разрешите текстовому элементу стать уже его содержимого, затем отдельно определите допустимые точки переноса внутри слова.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

Нужны два независимых правила: минимальная ширина `0` и перенос, разрешающий разрыв в любом месте слишком длинного слова.

</details>

<details>
<summary>Решение</summary>

```css
.flex-row p {
  min-width: 0;
  overflow-wrap: anywhere;
  margin: 0;
  flex: 1 1 auto;
}
```

`min-width: 0` снимает автоматический минимум текстового flex item, а `overflow-wrap: anywhere` создаёт точки переноса без удаления символов. Для ручной проверки сузьте область результата примерно до `640 CSS px`: label, кнопка и все символы слова должны оставаться видимыми, слово должно занять несколько строк, а горизонтальная прокрутка не должна появиться.

</details>
