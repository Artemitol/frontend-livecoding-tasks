# Цепочка сравнений

Песочница для выполнения — [Programiz](https://www.programiz.com/javascript/online-compiler/).

## Условие
```javascript
// Не изменяя код, предскажите две строки вывода и раскройте оба сравнения слева направо.
// Объясните, как промежуточное boolean-значение участвует во втором сравнении каждой цепочки.
// Используйте консольный JavaScript без ESM и browser API.

const ascending = 1 < 2 < 3;
const descending = 3 > 2 > 1;

console.log(ascending);
console.log(descending);
```

<details>
<summary>Подсказка 1 — куда смотреть</summary>

Сравнения одного уровня вычисляются слева направо, а не как математическая цепочка.

</details>

<details>
<summary>Подсказка 2 — с чего начать</summary>

После первого сравнения подставьте его `true` или `false` во второе.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

При сравнении с числом `true` приводится к `1`: получаются `true < 3` и `true > 1`.

</details>

<details>
<summary>Решение</summary>

```text
true
false
```

Первое выражение читается как `(1 < 2) < 3`, то есть `true < 3`. Второе — как `(3 > 2) > 1`, то есть `true > 1`; после числового приведения это `1 > 1`.

Ожидаемый результат: `true`, затем `false`.

Ручная проверка: запустите блок и отдельно выведите `(1 < 2)` и `(3 > 2)` перед вторым сравнением.

</details>
