# Три обновления счётчика в одном событии

**Учебная цель:** Исправлять серию обновлений счётчика с учётом batching и предыдущего состояния.

| Метаданные | Значение |
| --- | --- |
| Технологии | TypeScript, React |
| Тема | Состояние React |
| Формат | Отладка |
| Уровень | Средний |
| Время | 15 минут |
| Навыки | функциональное обновление state, batching, отладка замыканий |
| Предварительные знания | useState и обработчики событий |
| Среда выполнения | React 19.2, TypeScript 5.9, Google Chrome 150.0.7871.101, development mode |

<details>
<summary>Теория</summary>

Значение `count` внутри одного render — снимок состояния. Несколько вызовов `setCount(count + 1)` используют один снимок, поэтому React получает три одинаковых намерения. Функциональная форма получает предыдущее поставленное в очередь значение.

</details>

## Условие

Исправьте обработчик `increaseByThree`: один клик должен увеличить счётчик ровно на `3`, а второй — довести его до `6`.

### Входы

- Нажатие кнопки `+3`.
- Начальное значение счётчика `0`.

### Выходы

- После первого нажатия отображается `3`.
- После второго нажатия отображается `6`.

### Ограничения и побочные эффекты

- Не используйте таймер, ручной flush или изменяемую переменную вне React state.
- Не объединяйте три шага в `setCount(count + 3)`: задача проверяет корректную очередь обновлений.
- Внешних побочных эффектов нет.

### Локальный fixture

```tsx
const root = createRoot(document.getElementById('root')!);
root.render(<BatchedCounter />);
```

### Стартовый код

```tsx
import { useState } from 'react';

export function BatchedCounter() {
  const [count, setCount] = useState(0);
  const increaseByThree = () => {
    setCount(count + 1);
    setCount(count + 1);
    setCount(count + 1);
  };

  return <button onClick={increaseByThree}>+3: {count}</button>;
}
```

### Примеры

#### Обычный сценарий

Из `0` одно нажатие даёт `3`.

#### Граничный сценарий

Следующее нажатие использует уже обновлённое состояние и даёт `6`.

#### Ошибка или пустой результат

Входных данных нет; ошибочный результат — любое значение, отличное от `3` после первого клика.

## Критерии готовности

- В каждом из трёх обновлений используется functional updater.
- Один click показывает `3`.
- Второй click показывает `6`.
- Решение не зависит от тайминга рендера.

<details>
<summary>Подсказка 1</summary>

Передайте в `setCount` функцию, а не вычисленное из текущего `count` число.

</details>

<details>
<summary>Решение</summary>

### Подход

Каждый updater получает результат предыдущего updater в очереди: `0 → 1 → 2 → 3`.

```tsx
import { useState } from 'react';

export function BatchedCounter() {
  const [count, setCount] = useState(0);
  const increaseByThree = (): void => {
    setCount((previous) => previous + 1);
    setCount((previous) => previous + 1);
    setCount((previous) => previous + 1);
  };

  return <button onClick={increaseByThree}>+3: {count}</button>;
}
```

### Сложность

- Время: `O(1)` на click.
- Память: `O(1)` помимо очереди React.

### Компромиссы и альтернативы

Для фиксированного шага допустимо `setCount((previous) => previous + 3)`, но оно не демонстрирует три последовательных обновления. `useReducer` полезен, когда переходов много или они имеют имена.

</details>
