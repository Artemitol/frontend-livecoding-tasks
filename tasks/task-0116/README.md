# task-0116 — Приведение объекта в трёх сравнениях

Песочница для выполнения — [Programiz](https://www.programiz.com/javascript/online-compiler/).

## Условие
```javascript
// Не изменяя код, предскажите две строки вывода и объясните, почему object проходит сравнения с 1, затем 2 и 3.
// Укажите, сколько раз вызывается toString и какое значение остаётся в current после вычисления выражения.

const object = {
  current: 0,
  toString() {
    this.current += 1;
    return String(this.current);
  },
};

const expression = object == 1 && object == 2 && object == 3;

console.log(expression);
console.log(object.current);
```

<details>
<summary>Подсказка 1 — куда смотреть</summary>

При нестрогом сравнении объекта с числом объект сначала приводится к примитиву.

</details>

<details>
<summary>Подсказка 2 — с чего начать</summary>

Проследите отдельный вызов `toString` для каждого из трёх операндов `object == число`.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

Метод возвращает строки `'1'`, `'2'`, `'3'`, которые при сравнении с числами приводятся обратно к соответствующим числам.

</details>

<details>
<summary>Решение</summary>

```text
true
3
```

Каждое нестрогое сравнение заново приводит объект к примитиву и вызывает `toString`. Счётчик последовательно выдаёт `1`, `2` и `3`, поэтому все части конъюнкции истинны.

Ожидаемый результат: `true`, затем `3`.

Ручная проверка: запустите блок и временно добавьте лог внутри `toString`, чтобы увидеть три последовательных вызова.

</details>
