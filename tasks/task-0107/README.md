# task-0107 — Каскад равных классов

Песочница для выполнения — [CodePen](https://pen.new).

## Условие
```css
/* Определите цвет фона обоих div и объясните, почему порядок class-токенов в HTML не меняет результат.
   Оба правила имеют равную специфичность, а .blue записано после .red, поэтому оба блока должны стать синими.
   Выполняйте в браузере через CodePen. */

.block { width: 50px; height: 50px; }
.red { background: red; }
.blue { background: blue; }
```

```html
<div class="block red blue"></div>
<div class="block blue red"></div>
```

<details>
<summary>Подсказка 1 — куда смотреть</summary>

Сравните специфичность селекторов `.red` и `.blue`.

</details>

<details>
<summary>Подсказка 2 — с чего начать</summary>

При равной специфичности выигрывает правило, записанное позже в CSS.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

Порядок слов в атрибуте `class` не участвует в каскаде.

</details>

<details>
<summary>Решение</summary>

Оба селектора — один класс, поэтому побеждает более позднее правило `.blue`.

Ожидаемый результат: оба блока имеют синий фон.

Ручная проверка: поменяйте порядок классов в первом `div`; его фон не должен измениться.

</details>
