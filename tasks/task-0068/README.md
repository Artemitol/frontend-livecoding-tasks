# var в отложенных callback

Песочница для выполнения — [Programiz](https://www.programiz.com/javascript/online-compiler/).

## Условие
```javascript
// Не изменяя код, предскажите все строки консоли и объясните результат через область видимости var и порядок синхронного цикла и timer callbacks.
// Укажите точное количество одинаковых строк и значение в каждой из них.
// Используйте консольный JavaScript без ESM и browser API, кроме встроенного setTimeout.

for (var index = 0; index < 10; index += 1) {
  setTimeout(function logIndex() {
    console.log(index);
  });
}
```

<details>
<summary>Подсказка 1 — куда смотреть</summary>

Объявление `var` относится к области текущей функции или скрипта, а не создаёт новую переменную для каждой итерации.

</details>

<details>
<summary>Подсказка 2 — с чего начать</summary>

Сначала синхронный цикл полностью завершится и доведёт `index` до значения, на котором условие станет ложным.

</details>

<details>
<summary>Подсказка 3 — почти решение</summary>

Все десять callbacks замыкают одну и ту же привязку и прочитают её только после завершения цикла.

</details>

<details>
<summary>Решение</summary>

```text
10
10
10
10
10
10
10
10
10
10
```

Цикл синхронно регистрирует десять timer callbacks и заканчивается при `index === 10`. `var` создаёт одну общую привязку, поэтому каждый позднее выполненный callback читает из неё одно и то же итоговое значение.

Ожидаемый результат: десять одинаковых строк `10`.

Ручная проверка: сначала запишите прогноз, затем запустите блок и пересчитайте строки; после этого временно замените `var` на `let` и сравните, как отдельные привязки меняют результат.

</details>
