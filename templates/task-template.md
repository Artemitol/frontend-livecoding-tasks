# Шаблон карточки задачи

Выберите один режим, замените все значения в `⟦двойных скобках⟧` и удалите второй режим вместе с этой инструкцией. Карточка использует ровно один профиль выполнения. По умолчанию оставьте один полный code block; если учебная задача действительно требует нескольких файлов, повторите blocks и добавьте matching language-appropriate `FILE: <path>` в каждый starter и solution block.
