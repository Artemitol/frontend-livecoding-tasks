Актуальный результат поиска

Исправьте поиск, чтобы старый ответ не заменял новый.

Условие

Пользователь быстро отправляет два запроса. Второй завершается раньше первого. На экране должен остаться результат последнего запроса.

Код — вставьте целиком в редактор

// Измени только функцию search.
// Не разделяй этот код на несколько файлов.

const localFetch = (query) =>
  new Promise((resolve) => {
    const delay = query === 'старый' ? 80 : 10;
    setTimeout(() => resolve(query), delay);
  });

async function search(query) {
  const result = await localFetch(query);
  output.textContent = result;
}

// Проверка
search('старый');
search('новый');

Готово, когда

  • на экране остаётся «новый»;
  • повторный запуск даёт тот же результат.
