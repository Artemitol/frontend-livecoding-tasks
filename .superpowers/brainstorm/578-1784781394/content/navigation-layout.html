C · Один общий каталог

Самый компактный по файлам, но Markdown не умеет настоящий поиск и фильтры. Есть риск снова получить перегруженную таблицу.

Моя рекомендация: A

  • Ученик не открывает дерево файлов.
  • Нет промежуточной страницы между выбором и задачей.
  • Одна задача может встречаться в нескольких подборках.

Ограничение GitHub Markdown

  • Ссылка не может сама узнать, из какой подборки пришёл ученик.
  • Поэтому «Назад» возвращает точно, а ссылка «Все подборки» служит страховкой.
